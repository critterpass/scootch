# Phu's Class

Phu's Class (Lớp Thầy Phú, todo.phusclass.com) is an iPhone app for people with
ADHD and for chronic procrastinators. A strict, round, tea-drinking teacher,
Thầy Phú, puts one task on your desk, waits for you to start it, and paces the
classroom while you do it. Everything else you have to do is on the chalkboard
behind him, so you always see the whole picture and only ever face one thing.

English and Vietnamese, from the first screen.

**Parked, 30 Oct 2026.** phusclass.com now belongs to a different app, Phu's
Class, the English-learning app, so this one's site moved from phusclass.com and
www.phusclass.com to **todo.phusclass.com**. In the App Store it is now "Phu's
To-Do: Strict Teacher" (English), "Phu's To-Do: Việc Cần Làm" (Vietnamese) and
"Phu's To-Do Dev". The API (`api.phusclass.com`, `api-dev.phusclass.com`) and the
email addresses stay where they were. The brand is rethought when the app is
picked up again.
